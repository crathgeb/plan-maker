Point docs.example.com at the new site

Guide v1Ready to follow9 Nov 2026

Move the docs domain from the old CMS to the new static site. You add two DNS records; Claude checks every old link still works.

What you need

  • About 30 minutes, plus up to an hour for DNS to update
  • Your login for the registrar that holds example.com
  • The Cloudflare Pages project from week 1 (Claude has its address ready)

Good to know: the old site keeps working until the last step, so nothing breaks while you do this.

Add the records

The two DNS records that point docs.example.com at the new site. Claude prepares them; you add them at your registrar.

At your registrar

About 10 minutes

Prepare the records

The new site's address, checked against the Cloudflare Pages project.

Open the DNS settings for example.com

Needs your registrar login

Sign in to your registrar, choose example.com, then DNS (sometimes called Zone editor).

You should see a table of records, including one named docs pointing at the old CMS.

Point docs at the new site

About 2 minutes

Edit the existing docs record, or add it if there isn't one:

Type:   CNAME
Name:   docs
Target: docs-example.pages.dev
TTL:    Auto

If it fails with "a record with this name already exists", delete the old docs A record first, then add the CNAME.

Add the verification record

About 2 minutes

Cloudflare uses it to confirm the domain is yours.

Type:  TXT
Name:  _cf-custom-hostname.docs
Value: <VERIFICATION_TOKEN>

You should see both records in the table. Saving can take a minute to show.

Check it worked

Make sure the new site answers on the old domain and old links land on the right pages.

Once DNS updates

Up to an hour after the last step

Check where docs points

About 1 minute
dig +short docs.example.com CNAME

You should see docs-example.pages.dev. If it still shows the old address, wait ten minutes and try again.

Check every old link redirects

Claude requests every URL from the old sitemap and lists any that don't land on the right page.

Open the site and confirm

About 5 minutes

Open https://docs.example.com and click through a few pages. Claude posts what the redirect check found.
