Overview

What goes in, what comes out, and where it runs.

Input

Markdown in docs/

One file per page. The folder structure becomes the URL structure.

Output

Static HTML in dist/

Deployed by Cloudflare Pages on every merge to main, with a preview for every pull request.

Build time

About 20 seconds

For 60 pages on the CI runner. Locally, dev rebuilds one page on save.

Commands

The commands you run, and what each one does.

npm run docs:dev
Serves the site at http://localhost:4321 and rebuilds a page when its file changes.
npm run docs:build
Builds every page into dist/, then checks every internal link. Fails on a broken one.
npm run docs:check
Checks links and redirects without building. Used in CI before the build.

Configuration

Every option in docs/site.config.json, with its default. Only title and baseUrl are required.

OptionDefaultWhat it does
titlerequiredThe site's name, in every page's title and the header.
baseUrlrequiredThe address the site is served from. Used for the sitemap and canonical links.
redirects"redirects.json"The redirect map, relative to docs/. Old URL to new URL.
draftsfalseBuild pages marked draft: true. On for previews, off for production.
 
{
  "title": "Example Docs",
  "baseUrl": "https://docs.example.com",
  "drafts": false
}

How a build runs

What happens, in order, every time the site builds.

  • Read. Every .md file under docs/ is parsed, with its front matter.
  • Render. Each page is rendered into the layout named in its front matter, else default.
  • Check links. Every internal link must resolve to a page or a redirect. A broken one fails the build.
  • Write. Pages, the sitemap and the redirect rules go to dist/.

Files

The files a build reads and writes, and what each one is for.

PathWhat's in it
docs/build.mjsThe build: read, render, check, write.
docs/site.config.jsonThe options above.
docs/redirects.jsonOld URL to new URL, one entry per moved page.

Terms

The words this reference uses, defined.

Front matter
The block of settings at the top of a Markdown file, between --- lines.
Preview
A copy of the site built from a pull request, at its own address, so changes can be read before merging.
